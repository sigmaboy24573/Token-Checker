
# BLUEWAVE TOKEN CHECKER

This is the official  ** Bluewave Token Checker**, designed for **Windows** only.

### Features:

Here are some of the key features:

- 2FA support
- Bio display
- Phone number
- Email
- Avatar URL
- Location information
- Flags
- Nitro status (doesn’t currently work)

### 🛠️ Installation Steps:

Follow these steps to set up the tool:

1. **Install Python:**
   Make sure you have Python installed. Download the latest version from [Python's official website](https://www.python.org/).

2. **Install the required libraries:**

   Open your terminal or command prompt and install the required dependencies using `pip`:

   ```bash
   pip install colorama pystyle requests
   ```
